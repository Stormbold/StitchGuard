# Release v0.1.0

First public release of StitchGuard.

## Highlights

- CLI: `compare`, `check`, `init`, `init-agent`, `report`, `agent-prompt`
- GitHub Action: `uses: Stormbold/StitchGuard/action@v1`
- MCP server: 5 tools for agent repair loops
- Examples gallery + Bad UI Zoo regression fixtures
- Live web demo: https://stormbold.github.io/StitchGuard/

## Install (from source)

```bash
git clone https://github.com/Stormbold/StitchGuard.git
cd StitchGuard
pnpm install && pnpm build
pnpm stitchguard compare examples/screenshots/target.png examples/screenshots/actual.png
```

## GitHub Action

```yaml
- uses: Stormbold/StitchGuard/action@v1
  with:
    target: ./design/home.png
    actual: ./screenshots/actual.png
    threshold: "0.90"
```
