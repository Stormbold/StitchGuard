# Roadmap

## Phase 1 — Public MVP (v0.1) ✓

- CLI `compare` command
- Pixel diff, heatmap, score
- Markdown + JSON reports
- Codex/Cursor/Claude repair prompts
- Example screenshots and tests

## Phase 2 — Web-App Capture (v0.2) ✓

- Playwright URL capture (`check --url`)
- Viewport and device presets
- Config file support
- Ignore regions

## Phase 3 — Agent Workflows (v0.3) ✓

- `--agent` flags
- `agent-prompt` command
- Project AGENTS.md generator
- Prompt modes: conservative, strict, refactor-safe

## Phase 4 — GitHub Action (v0.5) ✓

- Local composite action
- PR comment summaries
- CI threshold gate
- Changesets release pipeline

## Phase 5 — Framework Intelligence (v0.4) ✓

- Tailwind class hints
- shadcn/ui pattern hints
- Stack detection from package.json
- 3×3 grid region analysis

## Future (not in scope)

- Flutter capture
- Figma plugin
- Automatic code patching
- SaaS dashboard
